Austrian Street Search

    API

    Interactive docs: Swagger UI · spec: openapi.json / openapi.yaml

    GET /search?q=<query>&limit=10&min_score=0.15 — fuzzy trigram search; trailing house/stair/door numbers are returned in street_number.

    POST /rebuild-index — re-downloads the Statistik Austria CSV and swaps the index atomically in the background.

    Response format:

    {
  "results": [
    { "address": "1110 Wien, Gasometer", "street_number": "A/1 3.Stock 22b", "score": 0.95 }
  ]
}

    Datenquelle: Statistik Austria — data.statistik.gv.at, licensed under CC BY 4.0.

    Changes: records are split per municipality/street-name variant, normalized for search, postal codes zero-padded, and duplicates and “Sonderadresse” placeholder entries removed.
